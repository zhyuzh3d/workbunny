# 0.14.1 实施与验证

本次按连续讨论收敛设置、工作面板、动作管理和语音入口，不改动已有聊天、记忆及自我理解的数据结构。

## 使用流程

- 设置、动作库、记忆库统一580px宽。新增200%角色大小，150%/200%放大时底部输入和状态控件保持100%宽度。四个内置形象与个人定制外形分组，个人模型可使用、识别、修改说明和移至废纸篓。
- 设定与相处输入至少三行，随内容增减高度。自我理解用紧凑只读条目，编辑打开单条弹窗，修订记录默认折叠；保留全局锁和并发修订冲突保护。
- 表单勾选统一开关，标题不换行。主人声音只需朗读一段给定文字，内部拆为三份；成功后才显示声音筛选开关，取消、超时或失败保留原模板。
- 智力分别适配WorkBuddy、DeepSeek、ChatGPT、Grok，各自保存地址、密钥和模型；获取模型、选择、测试后保存。直接API不被WorkBuddy离线阻断；任务监督和免费的后台整理仍等待WorkBuddy。固定四种思考选择；服务商不支持的档位按明确规则映射并提示。
- 新语音入口使用豆包语音。API Key、模型、音色和默认地址即可，内部自动填写模型版本请求头。公共音色表可选，也可手填复刻音色。兼容已有HTTP配置，未配置的新用户不显示旧模板编辑器。HTTP正常结束按最新文档允许EOF；JSON损坏、业务错误、取消和网络中断仍失败。
- 工作与日常使用当前任务、持续关注、WorkBuddy、自主生活、系统权限五个分页。设定任务为单输入框弹窗，复用正常对话安排和执行；删除独立验收输入、执行模型选择和辅助输入。当前任务和持续关注可暂停或取消；取消Bunny跟进不声称停止已提交给外部软件的工作。
- 自主生活默认使用应用数据目录中的creations，不要求手工授权表单或选题。空闲15分钟且前台、任务和记忆维护均空闲才尝试，延用免费模型、每天两次尝试、至少6小时间隔和夜间安静预算。暂停持久化，取消终止当前请求；可修改以后作品目录，不移动或删除已有作品。作品只在专用目录新建且核验内容，代码不自动执行。活动和作品按当前场景写入加密任务记录，保留既有兴趣与自我目标机制。

## 名字唤醒与菜单

旧“只在我叫它时才说”实际上修改了工作提醒开关，没有限制语音入口；新版明确使用asr.wakeOnly在模型请求前拦截未叫名字的话。仅限制自动语音，文字输入保持直接对话。每句话先叫名字；名字/其他叫法修改时重启识别器，清掉旧名字命中缓存。

两条原生ASR路径使用macOS Foundation本地转拼音，忽略声调匹配句首称呼，任意中文自定义名字均走同一算法，不依赖某个固定名字的词表。例如“倩倩/芊芊”匹配，句中出现名字不唤醒。外文名先提供识别提示，可额外填写中文叫法。SpeechAnalyzer使用AnalysisContext，旧SFSpeechRecognizer使用contextualStrings。通过本地名字门槛后仍复用正常回复的那一次语义判断，没有额外付费唤醒调用。

这是一道基于ASR文字的近音门槛，不是专用音频关键词模型。同音称呼和普通词语本来就有歧义；外文名的任意中文误听也不能自动穷尽。不能据此声称真人声学唤醒准确率已通过。声音筛选是独立可选的本地近似筛选，也不能用于身份认证。

删除“按住说话”的菜单、IPC、预加载接口及录音浮层。自动聆听和文字输入是唯一对话入口。旧系统按句结束并自动重连，保留权限与联网选择。菜单栏图标点击仅显示已有窗口，不再切换隐藏；文字输入菜单显式恢复鼠标响应、激活窗口并打开输入框。

## 验证

- 离线回归覆盖模型/密钥隔离、真实HTTP模型查询及SSE回复、豆包分片音频/正常EOF/错误/取消、声音录入原子替换、默认自主创作与暂停取消、百分比原子协调、记忆与数据迁移。
- 原生两条识别程序重新编译；无麦克风调用的自测覆盖自定义名字、同音字、外文及别名、句中误触发和改名后旧称呼不命中。
- 隐藏Electron窗口验证真实HTML/预加载/资料库的自我理解编辑、修订折叠、设置保存、任务分页和单框交代。
- 完整应用隔离验证四模型、动作实际回执、动作编辑弹窗、个人资源增删、三行自适应、四种思考档位、豆包精简流程、开关及150%/200%控件宽度。所有数据位于一次性测试目录，没有使用用户密钥调用付费API。
- 真实云端账号的模型/音色权限与真人唤醒效果需要使用者实际验证；本轮不将模拟服务或纯文字自测称作云服务/声学准确率验收。
