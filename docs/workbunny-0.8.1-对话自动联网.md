# 0.8.1：WorkBuddy 对话自动联网

2026-10-27。修复的是“模型可以对话，但没有搜索工具”的能力缺口，不改长期记忆、人格、场景权限或工作分工。

## 原因与实现

此前Bunny通过当前登录账号的本地 broker 调用 `/v2/chat/completions`，只传消息、思考强度和回复格式。它没有继承WorkBuddy客户端的工具执行环境，也没有提供搜索工具。模型知道某个网站或自称查过，不能证明发生了搜索。

不能给所有模型加一个未经验证的 `enable_search=true` 就宣称联网。作为对照，[腾讯TokenHub当前官方文档](https://cloud.tencent.com/document/product/1823/132358)规定该平台Chat接口使用 `web_search_options`，Responses使用 `web_search`；这不是Bunny当前调用的WorkBuddy接口合同。本次核对本机WorkBuddy 5.9.2分发代码及真实服务，确认其原生WebSearch使用 `POST /agenttool/v1/search`。

现在普通WorkBuddy对话默认提供一个只读搜索函数：

1. 同一次对话推理判断是否需要实时公开信息；需要时调用搜索，不额外增加一个“是否联网”的模型判官。
2. 搜索仍经已登录WorkBuddy的本地授权通道，发送简短主题，取得网页标题、网址和摘要。不复制账号token、不要求新增API Key、不修改其他云服务的付费开关。
3. 模型读取实际搜索结果后产生正常回复。普通陪聊仍可只用一次模型请求；搜索最多两轮、三次查询，原对话55秒总时限覆盖后续请求。
4. 新闻、天气、价格等按需搜索；本轮常见的明确“不联网/不要搜索”表达会关闭搜索入口。后台Doze、Dream、压缩与内部状态汇报不启用搜索。

本轮对话范围是 **WorkBuddy账号路径下的模型**。外部DeepSeek/Grok官方API仍保持原有调用方式，不假定不同平台拥有相同搜索参数或权限。

## 回复、来源与数据

- 支持标准JSON工具调用及SSE分片参数，严格限制工具名、数量、ID和参数大小。工具前言、函数参数、搜索JSON和推理正文不进入气泡或TTS通道，最终回复仍经过原有应用协议校验。
- 来源在气泡下方以最多三个标题按钮独立展示。只允许打开本轮真实搜索返回的公开HTTP(S)网址，拒绝伪造来源、危险协议、内网IP和其他窗口直接调用。
- 新轮次、场景切换、记忆变更及锁屏会清除旧的可打开来源。迟到或被打断的搜索不展示。
- 对话的来源标题与网址随助手消息保存在本地加密库，继承该消息的场景下限；搜索原始结果不作为新用户事实或人格设定写入长期记忆。
- 搜索词限制为简短公开主题，可识别密码/密钥不外发，不把整段历史或角色设定作为搜索请求。网页内容是待参考数据，不能扩大工具权限。文本保护仍是有限规则，不宣称通用DLP。
- 搜索失败会把“未能核实”反馈给模型，不用空结果冒充成功；不悄悄换模型，也不启用命令、文件写入或其他操作能力。

## 验证

当前账号的搜索端点真实返回网页结果，耗时约1秒。隔离公开查询中：免费Hy3完整搜索与回答约5.9秒，DeepSeek Flash/high约6.2秒，均实际搜索一次并返回三个来源。另一次没有使用“搜索/联网”字样的天气提问也自动搜索，约5.7秒返回。以上是少量功能探针，不是普遍延迟保证或所有模型的质量评估。

完整源Electron主链路使用临时资料库、随机测试密钥、关闭监听/TTS/监视和免费Hy3，验证了真实IPC、回复协议、搜索、气泡及SQLite中两条合成对话和来源元数据一致，最终退出码0，约5.1秒返回三个来源；没有音频负载。该隔离测试注入“会话已解锁”的fixture前提，不代表主机锁屏状态，不操作真实桌面，也没有写入正式聊天。

定向回归包括：普通聊天不搜索、失败和取消、密钥搜索词阻断、来源协议限制、次数和时限、缓存去重、模型用量聚合、SSE分片工具调用、最终回复校验，以及来源区域的高度/滚动/安全文本渲染。

复测入口：`tools/test-conversation-search.js`、`tools/test-workbuddy-transport.js`、`tools/test-reply-request.js`、`tools/test-bubble-ui.cjs`。显式执行真实账号端到端验收使用 `node_modules/.bin/electron tools/test-web-search-live.cjs`，不会读写正式聊天库。

搜索接入依赖WorkBuddy当前版本的账号通道和搜索服务；若将来接口或权限改变，应显示失败并保留现有对话能力，不能仅凭参数已发送就宣称搜索成功。源代码、模型额度与联网搜索服务的可用性分别验证。
