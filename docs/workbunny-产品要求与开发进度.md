## 一、产品是什么

一个常驻 macOS 桌面的透明置顶 VRM 玩偶，五件套能力：

| 能力 | 现状 |
|---|---|
| **看** | 透明无边框置顶窗口，三档大小（50% 半身 / 100% 全身 / 150% 全身+撑窗），可换 VRM 角色 |
| **听** | macOS 系统语音识别（SpeechAnalyzer）常驻监听，麦克风钉死在 USB Live Camera audio |
| **想** | 默认走 WorkBuddy 账号额度；也可填自己的 API Key（DeepSeek / 豆包 / Grok / NVIDIA Nemotron） |
| **说** | 默认 macOS 系统 TTS（离线、立刻出声）；可选本地 Qwen3-TTS GGUF 或远程 API |
| **动** | 92 条动作归入 20 个语义槽位，同类随机轮换，不重复上一个 |
| **盯** | 只盯 WorkBuddy 任务的状态与结果，任务名显示主人原话，看完可打钩收起 |

主人对它的总要求一句话：**可爱、聪明、有用**，并且"你要把自己当做产品经理、产品设计师，主导推动它走向更优更好"。

## 二、主人提过的要求（按主题归类）

### 2.1 形态与运行
- 能在 macOS 上**真实运行**，透明置顶，不挡活儿。
- 软件名 workbunny，娃娃叫 baby，**不要叫"小伴"**。
- 授权我直接自主安装依赖、编译运行、反复迭代，不需要逐步等确认。
- 项目要**提交到 GitHub 仓库**（`zhyuzh3d/workbunny`）。
- 异常退出要能自己恢复（看门狗 + 正常退出不重启）。

### 2.2 形象
- 以 D 形象为主；提供多个角色可切换。
- 角色名依次用中文女孩名：**婷婷、可可、阿雅、琪琪、美莉**。
- 最后一个角色（美莉）亮度过高，要调暗。
- 三档身高：50% / 100% / 150%。50% 只露上半身且头部在主要视觉区；100% 与 150% 全身；150% 同步撑大窗口；变小不收窄；角色始终居中。
- 新 VRM 要能直接切换，不要每次改代码（58.vrm 曾因非标准格式卡住，最终目标是像 BCDE 那样即换即用）。

### 2.3 动作系统（本轮最大改动）
- 主人整理了一份 **92 条高质量动作清单**（含原本已加载的），要求整体替换现有动作库、全部重命名、**记录原文件名以便核对**、合理分类。
- 设计意图原话："**把相似的动作都归类，同一类随机使用，这样可以避免全部进入上下文造成冗余**"。
- 站立动画**脚不能打滑**（左顾右盼那种不滑的要做成基准）；要求先在全网找脚步稳定的方案。
- 点击角色不同部位触发不同类型动作：点头/拒绝、上身害羞腼腆、下身不高兴，**带随机概率、不要绝对化**。
- 动作列表弹窗要能分类列出全部动作、点一条播一条；**只能从 macOS 右上角状态菜单进**，主界面和设置里都不给入口。

### 2.4 语音
- ASR 要**持续监听**而不是持续调大模型；没人说话就保持空闲、偶尔自己动一动。
- 麦克风必须用 USB 那个（其他麦收不到音）。
- 每次启动不要反复弹授权框 —— 要自动授权/记住授权。
- 左下角监听按钮：工作时绿色（不动画）、听到声音时显示电平、关闭时灰色；左端固定在角色脚下；听到内容时最大宽度=窗口宽度，超出向右滚动；风格与上方状态条一致。
- **默认用 macOS 系统 TTS**，要考虑兼容最近至少五年的 macOS；用户嫌声音难听时，**角色要主动提示去设置里配置**。
- 设置里可下载 Qwen3-TTS 1.7B 的 GGUF 最小量化版本，下完直接选音色生效；也可上传一个 ≤2MB 的克隆音色文件。

### 2.5 对话大脑
- 大模型用 WorkBuddy API 额度；对话时输出动作标签。
- 设置里可切自己的 API Key，**只支持** DeepSeek 官方、豆包、Grok、NVIDIA Nemotron 四家。
- 默认 WorkBuddy 模式用 auto（下拉选模型 + 思考强度）。

### 2.6 对 WorkBuddy 的监督
- 只关注**任务执行结果和任务状态**，不要盯着命令行执行反馈。
- 任务状态文字显示主人原话；说的是 URL 就显示 URL，不要故意过滤。
- 状态文字组件可上下轮播；**鼠标划上去停止滚动，移开后重新计时**。
- 状态条右侧一个 ✓ 按钮，点一下收起当前这条；没有任务消息就显示"空闲中"。

### 2.7 界面与交互
- 用户说的话也要显示在下面。
- 左下角麦克风状态不要和对话输入框重叠；上方状态文字与右侧喇叭、设置按钮要**竖向居中对齐**。
- 右上角按钮和左下角监听按钮，都要加**和任务文字控件一样的阴影**。
- 设置窗口、动作列表都要**单独弹窗**，不限制在角色窗口里。
- 交互控件上鼠标划过去变手型。
- 设置齿轮图标；任务状态条加宽但不碰到右侧按钮。
- 切换角色时其他 UI 保持正常，角色区显示转圈等待图标，不要全空白。
- 右下角加**版本号小字**，可被监听文字宽度覆盖。
- 底部语音按钮识别到文字时，宽度**自适应内容**，不要一下子撑满。
- 整个设置界面"保持简单、流程自动根据用户选择切换（显示最少但足够的控件）、排列美观"。

## 三、技术架构

**栈**：Electron（主进程）+ three.js（VRM 渲染）+ 原生 ASR 二进制（SpeechAnalyzer）+ `/usr/bin/say`（系统 TTS）+ Node 侧 LLM 客户端。

```
buddy-pet/
├── src/main/
│   ├── config.js        唯一真相源：92 条动作表、20 槽位、提示词、服务商、默认配置
│   ├── index.js         窗口/托盘/自检/面板窗口/监控
│   ├── tts.js           三档发声引擎（system / qwen / remote）
│   ├── llm.js           统一 chat()，按能力注入 thinking
│   ├── asr.js           常驻监听、设备钉扎、回声规避
│   ├── monitor.js       WorkBuddy 任务状态与结果
│   └── avatars.js       五个角色与中文名
├── src/renderer/
│   ├── index.html/app.js/style.css   主窗口（角色 + 状态条 + 语音条 + 输入框 + 版本号）
│   ├── panel.html/panel.js/panel.css 独立窗口：设置（四 tab）+ 动作库
│   └── assets/motions/               92 个 .vrma，文件名即 key
├── tools/               切段、能量曲线、打包、截图自检等
└── dist/                打包产物（当前陈旧，见第五节）
```

**四个关键设计**

1. **槽位（slot）机制**。92 条动作归入 20 个槽位（idle/work/greet/bye/cheer/praise/sign/dance/tease/refuse/angry/shy/think/sorry/tired/thanks/surprise/pose/motion/talk）。**提示词只列 18 个槽位名**，模型输出 `<m>cheer</m>` 这类类名；代码在该槽里随机挑一条并避开上次挑中的。上下文不冗余，同类还会轮换。
2. **动作文件即 key**。`assets/motions/<槽位>_<变体>.vrma`，配置表里每条带 `src` 字段记原包目录/原文件名，可一对一回查核对。
3. **切段 + 贴地补偿**。能量曲线自动选窗口（0.1s 分箱、4.5s 滑窗）；逐帧贴地改为**切动作时算一次常量补偿**，解决脚部打滑。
4. **自检可注入面板窗口**。自检脚本支持 `@panel:<kind>:` 前缀，把 JS 注入设置/动作面板窗口执行并回读返回值 —— 这是本轮才补上的，此前四个 tab 的点击全落在主窗口、报了 null 却没人发现。

## 六、关键决策记录（为什么这么做）

1. **默认系统 TTS，不用 A1X 远程**。A1X 是内网地址（192.168.124.31），换网络就废；每句还有约 2 秒空档。`/usr/bin/say` 自 OS X 10.7 就在，兼容五年绰绰有余，且离线、零成本、立刻出声。远程档保留为可选。
2. **动作用槽位而不是全量进上下文**。92 条动作名全塞进提示词会大量挤占上下文且模型选不准；改成给 18 个类名、代码在类内随机轮换，上下文干净、动作还不重复。
3. **设置按"她身上哪一部分"分 tab**。主人脑子想的是"她的脸/耳朵/脑子/嘴"，不是"llm 配置 / tts 配置"。每页只显示当前选择需要的控件，选系统语音就不会冒出一大片 API 地址。
4. **自检要注入面板窗口**。截图在显示器睡着时全黑、且当前模型读不了图；把面板 DOM 回读成文本，才是能判决成败的观测。上一轮四个 tab"验证通过"是假象——点击其实全落在主窗口报了 null。
5. **三档大小是三套取景，不是三套缩放**。50% 是半身构图、100%/150% 是全身构图；窗口基准尺寸永远存 100%（400×620），150% 只撑窗口不改基准。
