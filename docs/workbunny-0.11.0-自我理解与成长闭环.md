主动活动默认关闭。每天最多两次模型尝试和两次问候/分享，间隔至少六小时，22:00—09:00静默。未回应不会跨日继续追问；前台对话优先，可撤销授权。不确定的联系不重发。作品文件变化时不继续声称原交付仍有效。

微信、QQ、公开平台经营、朋友圈互动与锁屏离线送达，按原计划仍需独立接入；本版不激活任何真实账号的自主社交。已有用户明确交代的微信/WorkBuddy代办路径继续沿用。

## 数据与一致性

自我条目是 private/2 中的强 schema persona 修订，唯一 state 控制头保存当前引用与锁。RoleView只提供抽象角色条目，不暴露证据；角色修订号与事实 sources 分离，保留普通来源范围规则。主人直接编辑可改锁定内容，后台提案不能改锁；迟到版本或来源变化拒绝提交。

旧共通与场景设定先进入加密迁移材料，初始化成功后退休旧明文人格输入，不再叠加三套人格。清空保留空控制头，避免旧配置复活。导出/恢复覆盖自我条目、锁及消息认知；恢复前校验新 schema，删除来源后撤出相关条目并修复引用。

旧记忆的日期和对象补索引采用附属 state，不重写原始记忆正文或来源指纹。检索关联不登记成来源 DAG 双向边；关联结果仍核验范围、状态和已知日期。
