# 0.12.0 记忆、理解与自主成长

2026-10-29。以现有 0.11.1 为基础，实现“回想经历 → 修正理解 → 形成兴趣与目标 → 实际尝试 → 回看结果”的统一闭环。保留唯一自我理解、review → reply → prediction、Dream、水位、加密 Vault 和 Secretary，不增加数据库、后台代理或独立反思定时器。

## 产品与数据约定

- 自我理解描述稳定的身份、价值、行为和兴趣；愿景写成“我希望……”，不能把愿望当已具备的能力。用户直接编辑、单条及整体锁继续有效。
- 用户/关系/相处策略是带适用条件、支持与反例、最近核验时间的认识，允许暂定、稳定、待重看。预测反馈关联本轮实际采用的认识；单次偏差先调整当前节奏，同类经历积累后由 Dream 修订，明确纠正优先。
- 在意的事和近期目标保存意义、下一步、来源、状态及复查时间，可探索、暂停、完成和放弃。兴趣从真实交流、选择和作品结果中积累；用户称赞不是唯一依据。目标不产生权限。
- 使用同一个加密 Vault 的有版本特殊记忆，按既有 domain/visibilityFloor 保存；每个分区的轻量控制头只引用当前版本。旧版本保留证据，来源级遗忘沿已有依赖撤回。自我理解继续全球唯一，具体经历不能借人格跨场景流出。
- 现有正文、配置及数据库格式不做破坏性迁移；旧认知元数据继续可读。关闭持久记忆时不读取旧成长数据。开发验收只使用隔离资料库和合成对话。

## 实施任务

1. **有界主动回忆**：在现有只读工具循环加入本地找记忆、读原文；复用日期/实体规范化与两跳检索。只允许读取已在本轮发现的来源，限制轮数、条数、正文与总预算；原文分段可续读。对检索结果应用纠正、可见范围、有效期及来源检查，不能把候选当确认。最终回答保存实际读过的来源，删除或换场景后停止旧请求；私人记忆不经联网工具外发。
2. **成长记忆**：新增小型 repository，负责当前版本、支持/反例、状态、期限、来源和并发快照检查。Dream 同一次调用可产生少量认识/目标补丁，与原记忆、水位和自我理解原子提交。拒绝伪造引用、越界来源和旧版本覆盖，跳过无效可选提案，避免堵塞合法整理。
3. **对话接线**：对话上下文按需提供认识和近期目标；预测可选记录使用的认识 ID，服务端限定到真实提供的条目。上一轮评估同时带回对应认识，维持评估先于回复。隐藏字段不进入界面正文、TTS或原话全文索引。
4. **兴趣与目标成长**：Dream 结合唯一自我理解、近期认识/目标、预测反馈和核验任务结果，形成兴趣假设、小步试验与持续愿景。锁定内容不被绕过；长期兴趣留在自我理解，具体目标/作品留在成长记忆和任务，避免重复维护人格。
5. **情绪与主动活动**：活动选择读取当前目标、兴趣和上下文，先判断是否有值得做/分享的事。情绪来自有依据的进展、误解和探索，短期表达衰减，长期目标保留。模型次数和联系次数分开；未回复不再联系，但可在既有授权内安静创作。保留真实作品回执、待分享结果、安静时段、撤权和前台优先。
6. **可查看与调试**：在“小天地”显示当前认识、目标、依据和状态，允许用户结束/移除；不自动打开授权。回归覆盖本地回查、规范时间、来源撤回、纠正、旧数据、锁、并发、中断、场景、未回复创作及实际文件回执；最后运行受影响既有回归、隔离前台和合成真实模型验收。

## 顺序及验收

依次完成成长数据契约 → 主动回忆/对话接线 → Dream 学习 → 自主活动与可见界面 → 反例调试和回归。每阶段更新本文，记录实际实现、验证及限制。开发前源码备份：`~/Library/Caches/workbunny-growth-backup/20261029-135450/source-before.tar.gz`。

完成标准：模糊指代能回查；用户认识能依据反例修订；兴趣/愿景能带出有来源的近期目标，目标产生实际作品并将结果用于后续反思；未授权、无新价值或用户未回应时保持合适的安静。长期相处质量需要后续真实使用观察，合成验收不替代长期效果。

## 实现与调试记录

- `companion-growth.js` 在原 Vault 中保存有版本特殊记忆和六个范围控制头。每分区最多八条认识、三个活跃目标、十四个当前条目；终态目标可退出当前集合，历史证据保留。控制头直接点读，正文按相关性和预算选入对话。支持、反例、核验时间、下一步、情绪和关联自我条目分别记录。归一化正文、条件和下一步的相对日期，采用原始 occurredAt/timezone，旧记录不会因后台整理变成新经历。
- Dream 同批准备可选成长补丁，消费前缀以外的引用不接受；认识只接受主人原话，目标可接受 Bunny 的探索意愿和真实任务。每次修改新增版本，和普通记忆、水位、自我理解在一个原生事务中提交；控制头与依据变动会拒绝旧提交。稳定认识至少需要两条不同主人来源；Bunny 仅仅声称“完成”不能关闭目标。移除条目后退出当前依据，保存精确内容的防复活标记，旧来源仍可按原有“彻底遗忘”级联删除。
- `conversation-recall.js` 只读本轮发现的历史来源，支持原文分段、纠正投影、有效期、范围、来源快照及总预算；OpenAI 兼容 SSE 和 WorkBuddy 通道共用工具循环。关闭记忆不启用回查，后台资料和工具结果不能授权动作。
- dialogue-v2 的 prediction 新增可选 basis，旧数据兼容；前台只保留实际提供的认识 ID，下一轮在评估前给出真实采用的认识版本。格式修复仍隐藏内部评估、预测、工具输出，最终保存时再次核验回忆快照。
- 探索、期待、进展和受挫从有来源的成长记录投影到表达状态，沿用原有衰减、范围、限幅和遗忘。具体目标保留，短期情绪随经历时间衰减。
- 主动活动参考唯一自我理解、相关经历和当前目标。创作与联系分别限额，未回复时允许授权内安静创作；最多四个实际作品待分享，满后暂停，先分享再做新作品。旧单个待分享任务字段自动兼容为队列。真实作品形成任务回执并请求既有 Dream 反思，源码仅证明文件写入，未执行即不声称运行通过。新界面提供依据、反例、状态和移除控制，换场景丢弃旧异步返回，不自动开通授权。

调试中发现旧 Dream“只形成记忆”提示与目标生成冲突，真实模型连续返回空目标。已统一为事实、自我理解、认识/目标三类输出职责，再验收成功。后续补充原始时间、前缀外引用、控制头并发、未回复创作与队列、SSE 分片、移除和场景切换反例。

验证：首轮 57 个相关隔离回归通过；新增六组真实加密库成长集成回放和实际兼容 SSE 工具传输通过。隔离 Electron 以真实 HTML/renderer/preload 验证自我编辑/锁、成长依据与移除、场景切换和授权/撤销。真实 Hy3 免费模型以合成数据跑通查记忆→读原话→Dream建立目标→按关联目标创作，三阶段合计约91.5秒，不代表普通单轮延迟或长期相处质量。正式资料库没有作为测试材料。

实施边界：愿景使用已有 identity/value/interest 分类，不另建一份人格；探索目标可以早于稳定兴趣，长期兴趣仍靠持续经历和结果逐步修订。语义归因、动机选择、人格抽象由模型判断，不能把有限规则检查当作完整语义证明；移除后的近义改写仍需模型遵守撤回意图。第三方社交适配器、自动执行代码和公开发布仍没有接入。
