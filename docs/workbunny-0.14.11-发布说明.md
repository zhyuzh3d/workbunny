# WorkBunny 0.14.11

macOS Apple Silicon 版本。

## 本版变化

- 修复 WorkBuddy 任务状态提醒：保留待播报的事件，改善任务完成、异常、等待和超时提醒，并避免因敏感标题导致提示丢失。
- 改进连续聆听中的回声过滤，减少识别到自身播报时误打断的情况，同时保留主人通过有效语音打断的能力。
- 包含兔耳女孩形象“芭尼”、内置 bunny 形象包和其他 VRM 形象，以及整理后的动作库。

## 安装与数据

下载 `workbunny-0.14.11-macos-arm64.zip`，先退出旧版，再将 `workbunny.app` 移到应用程序目录。已有设置、个人资源和加密资料保存在用户数据目录；安装前建议备份。

安装包使用本机开发签名，**尚未经过 Apple 公证**。Apple Silicon、macOS 26.5.1 已在本机构建与安装验证；其他 Mac、macOS 13/14/15 的实际体验尚未验收。任务播报及回声过滤的真实设备表现受环境和音频设备影响，仍需在实际使用中验证。
