# workbunny v0.2.15 收音恢复与设置验收

## 收音故障与修复

故障时原生进程存活、麦克风已授权，但指定 USB 输入没有持续音频数据；旧程序在 `AVAudioEngine.start()` 返回后就显示“在听”，没有验证实际缓冲到达。切回系统默认输入并重建音频链路后，重新收到真实音频。

此次修复：

- 默认使用 macOS 当前输入设备，不再自动优先绑定 USB；指定设备启动却无数据时尝试系统默认输入。
- 等实际音频缓冲到达再报告就绪，准备资源、连接和重连期间不显示健康的绿色状态。
- 原生层持续监测音频输入，超过 4 秒无数据重建；主进程以独立心跳检测子进程卡住，超过 6 秒无心跳重启。
- 修正持续识别停止时未真正退出、快速关开后遗漏恢复，以及闭麦自愈计时被心跳反复重置的问题。原生会话定时器保持强引用，避免静音收句和闭麦恢复检查失效。
- 新 Mac 按请求语言准备系统识别资源，安装期间显示“准备语音资源”，避免误选已安装的其他语言，也避免下载被短启动超时打断。
- 末尾标点或空白修正不再单独作废已经发起的同一句模型请求；仍等待识别器最终结果确认文本。

正式安装版已收到 4410 帧的首个音频缓冲，并持续产生音量事件。快速关闭再开启监听后重新就绪。此次自动验收采样中收到 60 个音量事件，没有收到用户识别文本；“实际说话后字幕与回答正常”仍需用户复验，不能用音量事件代替。

## 设置与角色

“外貌”改为“角色”，添加五行“设定”和“怎么称呼你”（默认“主人”）。默认设定：

> 我是你的桌面小助手，陪你更轻松地使用 WorkBuddy。我会留意工作进展、帮你协调任务，也愿意陪你聊天、听你说话。我很喜欢和你待在一起：忙时帮忙，闲时陪伴。

名字、设定、称呼进入实际对话使用的系统提示词，保存后下次对话生效。

“语音”同时保留“试听一句”和“保存”；CHP 配置帮助链接增加 GitHub 图标。各标签保留未保存编辑，实时参数按顺序写入；只提交改动字段，避免其他标签旧值覆盖当前配置。配置文件原子替换且权限为 0600，写入失败保留原配置与待保存内容。关闭窗口前等待已经提交的写入结束。已保存的 CHP 音色在尚未重新获取音色列表时仍显示原选择。

## WorkBuddy 与移植

默认账号通道仍为 WorkBuddy，不复制登录 token。正式应用通过当前登录账号测试 Hy3，约 2.1 秒返回“连接成功”，消耗 0 额度。当前用户已自行选择 Grok，实际获取 8 个模型；修复与安装保留该选择及密钥，不强制改回默认。DeepSeek 尚未进行真实密钥调用验收。

任务监听支持 UTF-8 中文被文件读取边界拆分，以及日志截断、替换后的恢复。新机器使用当前用户的任务目录；唤起 WorkBuddy 按应用标识定位。兼容目标为 Apple Silicon、macOS 26+，详见仓库 `docs/workbunny-macOS安装与兼容.md`。
