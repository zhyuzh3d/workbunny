# workbunny 0.3.1 迭代与验收

2026-10-25，延续 [产品目标](../concept.md) 与 [自主迭代路线](workbunny-自主迭代路线-2026-10-25.md)。本轮重点是把桌面行动基础跑通、修复记忆面板实时性，并用测量确定语义记忆的下一步。

## 已实现

- **窗口坐标修复**：CGWindowBounds 实际返回 `X/Y/Width/Height`，旧解析仅接受小写，导致真实窗口全部被过滤。现在兼容两种键名，继续拒绝零值、负值和非有限尺寸；增加直接执行 Swift 的回归自测。
- **操作时鼠标穿透**：视觉任务运行期间，桌面角色不截获发给目标窗口的点击；悬停事件也不能重新打开交互。停止后恢复原有悬停逻辑。
- **记忆面板实时更新**：写入、确认、纠正、遗忘、恢复后发送不含正文的失效通知。面板合并刷新，保留筛选、已加载页数和滚动位置；编辑期间保留草稿。过期异步结果不能覆盖新分类、搜索或刚打开的编辑器。写消息时不额外统计整库。
- **钥匙串等待隔离**：本机实测新包可能在 `safeStorage.decryptString` 等待系统授权；同步调用会卡住 Electron 主线程。正式安装包现在由同包辅助进程读取，主窗口、设置和停止入口继续响应；两分钟超时、锁屏或退出会终止等待。资料库未完成初始化前，不允许对话和桌面任务，也不建立明文或空白替代库。
- **辅助进程访问边界**：解钥前后，原生模块用内核进程信息核验“辅助进程—主进程”的实际可执行路径，均须来自同一个正式安装包。直接从终端调用辅助入口会拒绝并且不返回密钥。通信只走父子进程管道，错误不附带密钥或子进程输出。此机制不声称能抵抗已经控制当前用户账号、可修改应用或读取进程内存的攻击者。开发模式仍使用原有 Electron safeStorage 直接路径。

**当前待办**：用户需要在 macOS 系统安全弹窗中完成本机钥匙串验证。工具禁止操作 SecurityAgent，也不能代填系统密码。因此本轮尚未验收“新版辅助进程成功解锁原有资料库”，也未向真实 WorkBuddy GUI 下发任务、未发送微信消息。完成验证后，优先验收正式包的任务派发—结果截图—验收闭环，再进行文件传输助手的单条无敏感内容实验。微信仍只允许截图和键鼠，不使用 AX、微信工具、API 或重启进程。

## 长期记忆：测出的不足

27 条跨年中英文合成改写问题，现有词法 Recall@5 为 **19/27，70.4%**，装入上下文为 **20/27，74.1%**。时间与同名实体案例表现较好，但低词面重合的事实和偏好会漏召回；不能据此宣称已实现稳定的多年语义记忆。

本机 NaturalLanguage 句向量精确检索在同一小集合上为 22/27；加入 1,000 条合成干扰后为 21/27，Top 1 仅 9/27。测试的 LSH 索引重排后只有 5/27，中文桶还发生严重聚集。**本轮不接入该 LSH，不迁移用户资料库，也不新增模型下载依赖。** 下一轮先扩大独立评估集，比较可离线的中英文语义模型、混合召回与精确重排；同时保持正文/向量加密、来源可追踪、遗忘传播和前台延迟预算。原始记录和人格继续独立于模型平台保存。

详细方法与可重跑脚本见 [词法召回评估](workbunny-memory-recall-2026-10-25.md)、[本地向量评估](workbunny-memory-embedding-2026-10-25.md)。这些是合成离线实验，没有使用个人聊天或付费模型。
