# 0.14.0 交互、感知与主动监督

基线：已推送的 `0d724d1`。保留 WorkBuddy 唯一模型通道、四个发行角色、个人资源隔离、加密记忆和现有授权边界。

## 统一约定

1. 动作目录是唯一数据源：发行动作不可改写安装包文件；个人 VRMA 在用户目录。分类、名称、语义描述、相对权重、启用和移除状态统一保存。随机选择按实际权重，指定动作只执行该动作；至少保留一个可用待机。
2. 角色实际开始播放后才确认执行。每次执行包含动作、分类、原因、形象和时间，保留最近五条；没有加载成功不能声称已经做了。当前形象、视觉描述、表情能力和最近动作作为当轮状态提供给模型。
3. 对话情绪与动作标签沿用现有协议，语义决定分类或具体动作，统一目录解析；表达中的动作不被朗读开始事件立刻覆盖。模型导入、描述编辑和删除在同一外观界面，四个内置模型始终受保护。
4. 用户讲话或开始打字立即中断当前朗读。记录 `interrupted`、原因与时间，取消旧预测资格；新的主动提醒等待用户空闲，不抢话。
5. WorkBuddy 监督使用有界注意队列：去重、合并、过期、安静时段、空闲判定和总频率限制。任务日志是外部资料，不能授权执行或改变设置。重要状态使用本地模板提醒，不调用模型。
6. 全局通知监听本轮暂缓：标准接口只覆盖本应用，通知中心可访问界面无法提供稳定完整的跨应用事件流。按用户补充要求，不为此增加高频轮询或后台模型请求；不读取通知私有数据库。
7. 监督追踪具体任务身份、进展、错误、等待用户、完成和预计耗时。超过预期、长时间无进展或出现异常才提醒；不把一次工具报错等同任务最终失败，不在恢复后重复发旧提醒。
8. 说话人筛选采用本地轻量声学特征与用户主动录制的多段样本，不上传录音；模板加密保存。先筛说话人，再判断是否对 Bunny 说话。近似声纹不作为身份认证，未录入、音质不足或设备变化有明确状态和关闭入口。
9. 扩大可用动作画布；macOS 限制原生窗口越过菜单栏时保留逻辑位置和画布偏移，让顶部可拖出屏幕，底部控件仍可找回。

原生 API 依据：[SpeechDetector](https://developer.apple.com/documentation/speech/speechdetector)、[AVAudioEngine 语音处理](https://developer.apple.com/videos/play/wwdc2023/10235/)、[AXObserver](https://developer.apple.com/documentation/applicationservices/1460133-axobservercreate)、[Electron 窗口边界](https://www.electronjs.org/docs/latest/api/base-window)。

成本约束：动作语义复用当前对话请求；每轮只提供分类摘要、明确提及的具体动作、当前形象和最近五次动作，限制附加上下文。任务预计耗时、异常触发与提醒去重本地处理，不为进度轮询调用模型。形象视觉识别仅在首次导入或用户主动要求时运行一次；说话人特征完全本地计算。
