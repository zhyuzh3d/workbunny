# WorkBunny：可免费再分发的 VRM 模型调研

调查日期：2026-10-31。目标是完整的、能随免费开源应用一起提供的 VRM 角色；免费使用、公开上传或能下载，不自动等于允许再分发。此文档记录网页与文件头核查结果；尚未把模型加入 WorkBunny，也未对其逐一做动作、表情、性能或穿模验收。

## 优先候选：作者明确允许再分发

1. **Shapell 女仆 VRM 1.0**：猫耳、双马尾女仆形象，VRM 现成文件。作者 sashii 为原作者的 CC0 素体自行制作服装并转换 VRM 1.0，商品页明确写不增加许可限制；原素体和服装均有来源。其 VRoid Hub 页面另外显示不得用于反社会、仇恨内容，应保留并核对实际下载文件中的许可和附带声明。来源：[作者 BOOTH 页面](https://booth.pm/ja/items/7421313)、[作者 VRoid Hub](https://hub.vroid.com/characters/7195679661303814523/models/3747193915661298415)、[原素体](https://booth.pm/en/items/1819556)。优先试听标准口型、眨眼、长发与手臂动作。
2. **茜犬 Akane**：犬耳人物，作者明确将模型设计、VRM、纹理等列为 CC0；包内还有 Blender 与 FBX。附带成人用途设定和材质／衣装，选用时需审视具体版本与显示内容；Unity 外部 SDK 与 lilToon 并不因此自动成为 CC0。作者页面：[Akane](https://booth.pm/zh-cn/items/8861598)。
3. **千駄ヶ谷 篠 / Sendagaya Shino**：VRoid Project 历史样本，官方说明该版本是 CC0；官方 Hub 对该版本标示允许再分发和修改。长直发女性角色。[官方说明](https://vroid.pixiv.help/hc/en-us/articles/360013482714-Sendagaya-Shino)、[官方 Hub](https://hub.vroid.com/characters/5860098757548846785/models/6567311261748429976)。
4. **桜田 史利矢 / Sakurada Fumiriya**：VRoid Project 历史男性样本，官方说明 CC0；官方 Hub 的该版本标示允许再分发和修改。[官方说明](https://vroid.pixiv.help/hc/en-us/articles/360014788554-Sakurada-Fumiriya)、[官方 Hub](https://hub.vroid.com/characters/6912965120285194650/models/2261505926203110716)。
5. **少女 A**：黑发水手服人物，另有猫耳和尾巴版本；作者声明 CC0，Hub 页面注明允许再分发与修改。作者也说明模型较旧、细节有不足。[作者页面](https://hub.vroid.com/characters/5271108759876567944/models/6364672505953706157)。核查该具体 VRM 的来源和附带第三方素材。
6. **Syaoty**：作者页面有多个版本，只有 `Normal_cc0` 包明确为 CC0，包含 VRM；`dress1_not_CC0` 不能跟着按 CC0 处理。[作者页面](https://booth.pm/en/items/2276392)。
7. **Kin**：作者声明 CC0 的和风、制服与动画风变体。文件版本差异很大，部分只有 `.vroid`、部分包含 VRM；选择具体包后核查许可与内容。[作者页面](https://booth.pm/ja/items/2246156)。
8. **式神 COLLECTION**：作者写明四个 VRM 角色采用 CC0，风格偏奇幻、非传统桌面秘书；其中 VANASYA 标注包含成人纹理。使用 VRoid Studio 制作，须核查具体成品及其基础网格、附件是否适用不同的 pixiv 或第三方条款。[作者页面](https://karindou.itch.io/vroid)、[VRoid Studio 官方指南](https://vroid.com/en/studio/guidelines)。
9. **Seed-san**：VRM Consortium 官方样例，作者 VirtualCast, Inc.。直接解析其原始 VRM 1.0 文件头：允许再分发及修改后再分发，要求署名，许可为 VRM Public License 1.0；51 个人形骨骼，包含双侧拇指骨骼及 18 项标准表情预设。不是 CC0；一些第三方页面的 CC0 说法与文件内容冲突。[官方原始文件](https://raw.githubusercontent.com/vrm-c/vrm-specification/master/samples/Seed-san/vrm/Seed-san.vrm)、[文件许可字段整理](https://github.com/Undi95/Hanami/blob/main/vrm/Seed-san.LICENCE.txt)、[许可文本](https://vrm.dev/licenses/1.0/)。
10. **100Avatars / Open Source Avatars**：发布方和创建者声明 R1、R2、R3 为 CC0，索引分别列出 100 个角色，提供各自 VRM、预览及直接下载链接；风格有卡通人物、机器人、动物，质量和表情配置差异大。[创作者声明](https://www.toxsam.com/projects/100-avatars)、[模型索引与逐集合许可](https://github.com/ToxSam/open-source-avatars)、[发布页](https://github.com/polygonalmind/100Avatars/releases)。旧仓库 README 曾提出原样销售限制，与后续 CC0 说明不一致；用于本项目的免费分发，仍应逐文件保存许可元数据；若涉及单独销售，需先厘清冲突。[Moon Girl](https://vtubeme.com/free-vrm-avatars/cc0/moon-girl) 的原始文件头已抽查：VRM 0.x、作者 Polygonal Mind、CC0、50 个人形骨骼、五个口型和基础眨眼；未实测运行效果。可在作者索引中按名字或风格继续筛选；300 为索引记录数，不表示 300 个均适合 WorkBunny。
11. **256Chinchilla / 256Hedgehog**：动物与吉祥物风格，不是日常人类角色；作者明确写 CC0、可再分发，包含 VRM，模型很轻。[龙猫](https://booth.pm/en/items/3816543)、[刺猬](https://booth.pm/ja/items/2064264)。是否适配双臂动作需要实测。

## 许可和来源有疑问，暂不作为已确认发行素材

- **Nova / Kai / Sky / Ember**：VTubeMe 页面声明这四个 VRM 为 CC BY 4.0、允许修改和再分发。直接解析 Nova、Sky 的 VRM 文件头：作者为 VTubeMe、`CC_BY`，各 54 个人形骨骼，含眨眼、五个口型和基础情绪预设。但文件名义上是 `MetaPerson Avatar`，VTubeMe 明确使用 Avatar SDK / MetaPerson，其上游一般条款对授权第三方使用模型有通知和可能的其他要求；VTubeMe 可能另有特别授权，现有公开信息不足以判断。除非明确确认 VTubeMe 有权将这些具体文件以 CC BY 再授权，否则不列入已确权包。[发布方声明](https://vtubeme.com/free-vrm-avatars)、[发布方技术说明](https://vtubeme.com/)、[上游条款](https://avatarsdk.com/eula/)。这是待核查事项，不是关于个别合同效力的结论。
- **VALID 的第三方 VRM 转换**：转换作者声称 VRM 为 CC BY 4.0，仓库索引共 234 个 `.vrm` 路径（Git LFS，含 `X_Non-validated`）；作者宣称支持 ARKit 52 表情。原始 VALID 作者仓库却标 MIT，且转换仓库指向了不同的旧地址，溯源说明不一致。两者不一定互相排斥，但要在入包前核实原始文件、转换权限、署名和实际下载可用性。[转换库](https://github.com/TLTMedia/valid-vrm-avatars)、[Google 原始库](https://github.com/google/valid-avatar-library)、[原始许可](https://github.com/google/valid-avatar-library/blob/main/LICENSE)。
- **VRoid 制作的其他第三方 CC0 角色**：创作者可对自己的设计或纹理声明 CC0，但当前 VRoid Studio 指南说 pixiv 提供的默认网格、服装网格及素材本身不是 CC0，具体旧版 CC0 样本例外；整份文件须核查底模、纹理、服装和版本。[官方指南](https://vroid.com/en/studio/guidelines)、[官方历史样本说明](https://vroid.pixiv.help/hc/en-us/articles/4402614652569-Do-VRoid-Studio-s-sample-models-come-with-conditions-of-use)。

## 与已有角色去重

WorkBunny 当前的可可 `AvatarSample_D.vrm` 元数据角色名为「千駄ヶ谷渋 / Sendagaya Shibu」。[历史 CC0 Shibu 的 VRM 1.0 转换版](https://booth.pm/ja/items/7421307)是同一角色的另一版，值得研究，但不应计作全新角色，也不能直接把旧版 CC0 声明套用到当前文件。当前 D/E/F/G 的来源、哈希和条款应继续按项目现有清单核对。VRoid 的当前 [AvatarSample A–Z 条款](https://vroid.pixiv.help/hc/ja/articles/4402394424089-AvatarSample-A-Z)也明确不是 CC0，允许范围内的使用和免费分发仍要保留具体条件。

## 技术验收建议

对每个选入文件保留原始下载链接、版本、哈希、许可原文和 VRM 内嵌信息；在 WorkBunny 里检查 VRM 0.x / 1.0 加载、标准眨眼与五种口型、左右手与拇指骨骼、头发/衣物物理、MToon 材质、站坐/挥手/拥抱动画的穿模，以及 Mac 上的加载速度和内存。被标为 CC0 的角色没有完整表情或只有简化骨骼时，仍可能不适合做可长期互动的桌面伙伴。Grab3D 的 [Character Mixer](https://grab3d.com/tools/character-mixer/) 可以输出 CC0 的 VRM 0.x/1.0，但官方写明仅 19 根骨骼、没有面部 blendshape，故更适合备选吉祥物而非当前 Bunny 主角色。
