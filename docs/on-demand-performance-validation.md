# Bunny 按需表演验收记录

日期：2026-11-13。范围为源码开发版与独立 `.data/dev` 生活场景，使用合成输入；安装版未更新。

## 实现结果

对话 LLM 可以在聊天回复中附带简短表演要求，也可以空首次正文。仅在提出要求时额外调用一次表演用途，携带固定提示词、当前形象完整精简编号目录和该要求。普通随机动作继续使用原路径。

编号解析绑定不可变快照；表演正文复用气泡、TTS 和取消机制。具体动作拥有加载和播放期间的身体使用权，低优先自动动作不抢占，主人输入和直接操作优先。表演循环有界展示，正常收尾恢复待机。延迟返回、延迟加载、过时转场和结束回执不能恢复已经取消的表演。

实际开始、完成、中断和失败状态进入身体上下文。`started` 区分尚未播放与已经开始，最近表演结果独立于普通待机保存并持久化；选中动作本身不记成已经做过。

调度和执行证据分别来自本机统一 MCP 的本次文字回执、播放器身份回执，以及 CGDisplayStream 局部像素。模型声称做了动作不单独作为播放成功依据。

兔兔与VRMA形象共用对话轮次、模型准入、`AvatarCatalogRouter`、编号快照、`Embodiment` 和动作回执；运行时只在相应渲染后端解释资源。剧场球、雪花属于包内效果，不要求外部道具。跨形象动作记录保存友好形象名称，避免把兔兔的剧场表演误记成芭尼的动作。调试切换使用统一MCP中的 `avatar_select`，状态使用 `avatar_status`，沿用UI设置和身体状态入口。

本机材料位于 `.local/performance-20261113/`：`run-a.png`、`run-b.png` 为VRMA局部画面；`theatre-ball-active-a.png`、`theatre-ball-active-b.png` 为兔兔剧场局部画面；`final-targeted-tests.log`、`context-tests.log` 与 `full-tests.log` 为离线结果。开发版运行日志中的 `[performance]` 仅记录计数、编号、动作键及播放阶段，不记录表演要求正文。

## 自动检查与边界

263项专项检查通过，覆盖主协议、表演协议、真实 `think` 编排、空首次回复、正文流式边界、声学提交门、第二次调用取消、输入接纳与完成分离、编号快照、姿态桥接、渲染器占用、迟到回执、完成看门狗、真实兔兔包及后续身体上下文。实际Electron的芭尼触摸交互验收也通过。合成回执用例与真实播放器验收分开计。

真实打断测试曾暴露空首次回复的旧请求仍留在待回应队列，导致新模型重新提出旧表演。已在通用对话调度器中增加 `consume()`，接纳表演后消费本轮待回应输入但保持活动轮次及取消能力；普通未处理输入仍保留。修复后的实际复测确认旧调用取消，新输入独立回答，不再续演。

一次新输入的真实模型回复曾在认知根对象带额外字段而校验失败；未记录其原始正文，无法确定具体字段。已补充合法完整协议示例、明确表演字段只能位于内层chat回复，并增加不含正文的固定字段位置诊断。严格校验保持有效，不从坏输出中执行动作；模型偶发协议错误仍不能被宣称完全消除。

全量334套检查中有10套未通过：9套集中于既有任务/视觉执行测试，替换回本次改动模块的HEAD版本后仍复现失败；另1套要求已打包应用与当前源码完全相同，因本次只更新开发源码而失败。本次未扩展修改这些任务和软件操作逻辑，也未为消除安装包一致性检查而发布安装包。基线复核材料在 `.local/performance-20261113/baseline/`。

ASR、AEC、VAD、分段、热词和TTS参数保持原值。既有语音输入与取消专项通过；本次实际打断使用新文字输入，真实麦克风插话和长时间语音交互尚需用户现场复核。

## 周期、自主变身与当前形象补充验收

本次继续使用源码开发版及 `.data/dev` 生活场景。相关21个文件共167项检查通过；补充的最终提示词回归也通过。全量测试的既有基线缺口仍按上节记录，本次不因此宣称全仓通过。

- 实际原地跑：片长500ms，8个完整周期、总计4000ms，仅一组开始/结束回执。实际轻快舞步：片长1000ms，4个完整周期。
- 新兔兔1.1.0：包摘要 `685195dca86bbc8fd5d7d95e23e20c679f81b0b01be499716939c0127a0405ae`。USB手机外放真实请求后，自主选择“耳朵拍回球”（4000ms）及“下雪啦”（约2625ms），均单次完整结束，走相同表演调度及身体回执。
- 自主变身直接使用主对话动作协议与统一身体能力，无额外选形象模型、无正式任务。实际逐个切换七个官方形象；自定义形象的编号、目录变化和执行等待使用独立夹具验证，本机未额外导入测试形象。
- 当前形象由实际body-ready确认。加载期间保留旧可见形象名，并单独标出目标名称；取消后重新确认仍挂载的旧身体。名字与人格身份区分，旧形象的动作仍保留当时的形象名。
- 文字新输入与手机实际语音插话均取消正在播放的表演；真实语音中断“快乐小碎步”保留 `phase:cancelled,reason:voice`。加载中取消、后续手选保护、切走再切回、迟到成功不播报和目录失效另有离线竞态覆盖。
- 真机发现声学提交门在表演已获准、形象仍加载时短暂关闭，被误当成整轮取消。修复为：准入前仍等待声学提交；已开始的加载按对话身份及取消信号保持，后续回复继续等待声学许可。未改ASR/AEC/VAD参数；新增实际think回归并重新通过美莉变身。
- 手机Aiden语音曾将“芭尼”转写为“巴黎”。通过正常对话让Bunny自己把七个形象专名加入既有额外热词；不改原始转写、不新增纠错模型、不改语音管线。实际识别结果与语义执行分开记录，不能把词表已提交冒充识别绝不会出错。

新材料保存在本机 `.local/performance-loops-20261113/`、`.local/avatar-capability-20261113/`。录制小样使用CGDisplayStream及CoreAudio/麦克风双轨，实际动作画面和两轨均有信号；正式成片的取景、剪辑与完整审片另记于制作案例，不能由本段测试代替。
