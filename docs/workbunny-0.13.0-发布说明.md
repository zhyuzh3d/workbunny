# WorkBunny 0.13.0

2026-10-30 · macOS Apple Silicon 公开体验版

本版将原本依赖开发者环境的桌面伙伴整理成可独立安装的软件，同时保留长期记忆、自我理解、人格锁、预测反馈和受控主动性。

## 主要变化

- WorkBuddy 是唯一模型通道：一键连接当前登录账号，无需复制 token；账号或连接变化时暂停旧请求与任务，不自动重复派发。
- 构建最低目标为 macOS 13：26 优先持续端侧识别，旧系统使用按次识别；联网识别需明确允许。播放期间自动半双工，无需用户配置回声消除。
- 四种发声入口：系统默认音色、本地 Qwen、标准 CHP、自定义 HTTP。HTTP 支持受约束的 binary/JSON/JSONL/SSE 配置、模型/音色查询或手填、脱敏导出及实际播放试听。本地 Qwen 至少需要16GiB内存，不限制M系列代数，权重单独下载。
- 数据库可在设置中安全迁移：暂停写入、checkpoint、关闭、完整复制与校验、原子切换；磁盘丢失时进入恢复，不另建空库。
- 默认100%窗口半身像；四个内置角色统一中文名：可可、阿雅、琪琪、美莉。
- 支持导入个人VRM，保存在用户数据目录，更新软件不覆盖。婷婷等个人模型不随公开包分发。
- 公开包含18个有明确许可依据的动作，附完整许可及署名。17个裸文件分发受限动作和60个许可待核实动作移出当前公开源码树与安装包，本机原有副本保留。详细依据与逐项清单见下文链接。

## 下载与安装

下载 `workbunny-0.13.0-macos-arm64.zip`，先正常退出旧版，再把 `workbunny.app` 放入本机应用程序目录。另提供带来源清单的干净源码快照，以及SHA-256校验文件。

本版使用稳定自签名身份，没有Apple公证。首次打开可能需要在macOS“系统设置 → 隐私与安全性”中确认允许。无需安装开发证书，不关闭系统安全检查。

安装后先连接并登录自己的WorkBuddy。需要语音时再授权麦克风/识别；桌面任务权限单独申请，连接不自动授予自主或社交权限。已有设置和加密资料沿用；迁移数据库后不要再启动不认识新位置的旧版程序，回退应使用配套的迁移前备份。
