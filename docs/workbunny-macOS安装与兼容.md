# WorkBunny 的 Mac 安装与兼容

适用于 0.14.1；已公开的 0.13.0 体验版保留独立发布说明。仅 Apple Silicon；应用、Vault、钥匙、桌面桥及可选 Qwen 运行程序按 macOS 13 目标构建，持续识别辅助程序单独要求 26。**目前实际运行证据来自 macOS 26.5.1；13/14/15 尚待实机验收。**

## 安装与首次使用

1. 如已有旧版，先正常退出。将应用放入本机“应用程序”或 `~/Applications`。站外自签名包没有苹果公证；遇到系统拦截，按照 Apple 的“隐私与安全性 → 仍要打开”流程处理，不关闭系统安全检查。
2. 打开设置中的“智力”，点击“连接 WorkBuddy”。没有安装时使用“下载安装”打开腾讯官方入口，安装并在 WorkBuddy 登录。Bunny 自动连接当前账号、获取可用模型，并使用当前用户的任务目录；无需填写 token 或修改 WorkBuddy 配置。
3. 首次使用语音时再授权麦克风。macOS 26 优先持续识别；旧系统或新版引擎不支持当前语言时，自动分段识别并重连，每段最多45秒。旧识别如需联网，必须在“听力”中明确允许；文字输入始终可用。
4. 默认使用系统默认音色。Qwen 本地模型需至少16GiB物理内存，权重单独下载；不限制 M 系列代数，体验通过试听判断。持续聆听会自动尝试回声消除；不支持时依靠识别文字过滤自己的声音。讲话或输入文字可打断朗读，无需配置回声参数。只保留自动聆听与文字输入；⌘⇧Space 开关自动聆听。
5. CHP 填标准服务地址与密钥，获取模型与音色。豆包语音填 API Key、选语音合成2.0或声音复刻2.0，选择或手填音色后试听；地址有默认值，内部模型版本请求头自动填写。获取音色列出官方公共音色，不代表账号已获授权，使用权限由试听确认。试听成功要求所选引擎产生音频并实际播放结束，不能用系统回退冒充。
6. 桌面任务另需辅助功能和屏幕录制权限。在“工作与日常”查看当前任务、持续关注、WorkBuddy进展、自主生活和系统权限。空闲超过15分钟可自动发起本地小创作，默认目录为应用数据目录内的 creations；可暂停、恢复、取消本次任务或修改以后作品的目录。每天至多两次免费模型尝试，间隔至少6小时；22:00–09:00安静。不会因此获得社交账号或外发权限。
7. 智力可分别选择 WorkBuddy、DeepSeek、ChatGPT、Grok。后三种填写对应 API Key与服务地址，获取模型后选模型和 none/low/medium/high，再保存或测试。各家独立保存配置。Grok部分模型不能关闭思考，none降为low；DeepSeek当前模型的medium按官方规则映射为high。WorkBuddy离线不阻断已配置的直接API对话，后台整理与工作监督仍等待WorkBuddy恢复。

官方入口：[WorkBuddy](https://cloud.tencent.com/act/pro/workbuddy)、[Apple 站外应用打开说明](https://support.apple.com/102445)。本轮不要求苹果开发者账号，不进 App Store。

## 数据位置与迁移

默认资料库为 `~/Library/Application Support/workbunny/vault`，配置、位置指针、模型和创作授权目录仍留在原应用目录。开发版独立使用项目 `.data/dev`，不会复制配置到日常应用。

设置“数据 → 迁移数据库”：选择目的父目录，Bunny 在其中新建 `vault`。迁移暂停对话与后台写入，checkpoint 并安全关闭数据库，复制完整密文与原钥匙封装，核对文件 SHA-256、SQLite 完整性和记录数，最后原子切换位置并重启。目标不得已有 `vault`，也不能与来源相互包含。原目录保留为带标记的只读快照，新版不会再打开它。

目的磁盘丢失、位置文件损坏或提交后指针缺失时进入恢复页，不在默认目录偷偷新建空库。接回原磁盘后重启，或选择当前已有资料库。迁移前中断恢复原库；提交后保留新位置，不能自动退回旧快照。旧于0.13的程序不认识迁移标记，**迁移后不要再运行旧版程序**；回退应同时使用迁移前的应用与资料备份。

同机改路径保留原钥匙身份。跨机器仍须通过“记忆与关系”的密码加密备份恢复，不能只复制依赖本机钥匙串的封装文件。外部接口凭据与系统权限在新机分别配置。

## 已有 HTTP 配置兼容

示例：[`http-binary-v1.json`](tts-profiles/http-binary-v1.json)、[`http-jsonl-v1.json`](tts-profiles/http-jsonl-v1.json)。模板不含服务地址和凭据。鉴权值须按服务要求填写；例如 Authorization 需包含服务所需的 `Bearer ` 前缀。

配置仅允许 HTTP/HTTPS、JSON 正文、有限参数和密钥绑定、字段路径、状态码及音频格式，不执行代码。支持 binary / JSON / JSONL / SSE，音频为24kHz单声道PCM16LE或WAV。云接口分片先合并后播放；Qwen 保留原有流式播放。最大文本2000字、音频60秒、响应32MiB，首音30秒、总响应90秒；取消会中止网络读取。未知格式、非音频、业务错误和提前断流均报告失败。

凭据留在主进程的私有设置中；界面只显示是否填写，导出只包含受约束的接口描述。正文内凭据必须引用 `$secret`，不能直接写在 JSON 中；地址禁止携带凭据。目录查询可选，不为获取音色额外索要云账号管理密钥。

## 构建与发行边界

开发构建需 Apple Silicon、macOS 26 SDK/Xcode 命令行工具、Node22以上、CMake和Git。`npm ci` 后执行 `zsh tools/make-signing-cert.sh` 创建自己的稳定签名身份，再构建。签名私钥不进入仓库，也不交给安装用户；不要为每次更新更换身份。所有原生组件签名失败即停止，不退回临时签名。

`tools/package.sh` 采用资源白名单，包含四个官方角色，排除个人导入模型、用户配置、记忆、权重和生成语音。公开构建仅复制18个明确许可动作和四个官方角色，个人模型及未核实素材不会进入安装包。设置“外观→导入个人模型”支持个人VRM并持久保存；默认100%窗口半身像。详见 [资源许可](../THIRD_PARTY_NOTICES.md)。

当前已完成本机隔离安装包的启动、界面、HTTP合成与WebAudio播放结束、坏路径恢复，以及原生最低系统和签名检查。素材分发处理见[逐项清单](workbunny-0.13.0-资源处理清单.md)。真实云服务账号、旧系统实机、另一台Mac的新用户首次下载/权限/钥匙串仍未验收。本机自动验收不代替其他Mac与旧系统实测，不据此宣称所有Mac已通过。

首次创建资料库时请留意 macOS 钥匙串授权。若等待超时，在“记忆与关系”点击“解锁记忆”重试，并在本次系统弹窗中完成授权；不要删除钥匙文件或旧资料库来绕过锁定。

## 动作与主人声音筛选

“动作库”默认展开分类，点击动作即播放，行内滑杆协调同类动作的百分比；编辑名称、含义、分类、循环与待机资格使用单独弹窗。权重0仅允许指定播放，不参与分类随机；至少保留一个启用且正权重的待机动作。内置动作移除后可恢复；个人 VRMA/VRM 删除移至废纸篓，不能删除四个内置模型。个人模型首次加载可用确认免费的 WorkBuddy 视觉模型生成一次说明，也可手工填写；没有免费视觉模型时不自动改用付费模型。

“听力 → 主人声音筛选”显示提示文字，点击开始后自然朗读一遍，程序内部切成三份。模板在本地加密，不保留录音，不产生模型调用。使用日常说话距离；换麦克风应重录。该方案是轻量声学近似，混合人声、相似音色、噪声或回放可能误判。默认关闭，不能用作安全认证；真实多人识别效果需要用户录入后实测。

“叫名字才回应”限制自动语音，不限制文字输入。每句话先叫名字；中文用 macOS 本地转写拼音匹配，外文名可补充中文叫法。改名或修改别名后自动重启识别器并更新名字提示。同音称呼与普通词语无法仅靠文字完全区分，仍由正常回复同一次语义判断筛选，不增加单独的唤醒模型调用。
