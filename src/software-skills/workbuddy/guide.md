# WorkBuddy 软件技能

先把主人多轮对话整理为完整任务说明，保留原始交办和来源。根据目标匹配实际存在的空间；没有合适空间就新建不属于空间的任务。优先使用 WorkBuddy 专用 AX 控件，失效时使用截图和键鼠。

输入前确认工作位置、模型和空草稿。提交后绑定唯一会话与消息标记，增量观察真实工作记录，不重新发送任务。当前草稿与任务无关时先保留。

最终答复属于执行证据。回收实际结论与产物，针对缺项在原会话继续检查；正常完成后极简汇报实际结果。主人指定微信渠道时只向该渠道交付，无法发送时保存待交付。

遇到恢复性故障，先重新观察并尝试可用替代方法。经验是可修正的方法，不是授权。

WorkBuddy只负责制作本轮产物，主人要求的微信交付由Bunny回收后执行。工作空间需要明确对应证据，执行软件名称不能作为选择同名集成项目的依据；无对应就继续无空间任务。

视觉兜底统一使用 screen.observe 的 frameId 和预览尺寸。文字按钮用 screen.action 的 label 本地定位；无文字图标与空白区域才使用 targetType 和预览图整数 pixelX/pixelY。操作后重新观察，画面引用失效就重新定位，不沿用旧坐标。
